# Аренда в Армении

Telegram Mini App: аренда без комиссии и предложения агентов. Лента загружается порциями по 12 карточек; фото, сетка, поиск; «Мои» и подача — сверху. Подписки — в фильтрах, уведомляют только об объявлениях, поданных в приложении.

Подача: жильё → адрес → цена → фото и необязательное описание. Телефон необязателен. Контакт — Telegram автора; без username — обсуждение публикации. Агент один раз заполняет имя, телефон и агентство для администратора; в карточке видны только агентство и комиссия. Даты аренды и время в пути вводятся вручную.

Жалоба содержит причину, пояснение и необязательные доказательства: ссылки и до 5 скриншотов через Telegram. Заявитель и доказательства доступны только заявителю и администраторам; решение — в разделе «Жалобы».

Бот открывает поиск, подачу и «Мои объявления». Администраторы получают отчёт за прошедший час, если были пользователи, и за предыдущий день после полуночи Еревана. Считаются уникальные пользователи каждого этапа; администраторы исключены. Учёт начинается с обновления, данные по часам хранятся 35 дней.

## Запуск

```sh
cp .env.example .env
# Заполнить локально BOT_TOKEN, BOT_USERNAME, ADMIN_IDS и PUBLIC_URL.
docker compose up -d --build
```

Нужен доверенный HTTPS. LIVE=1 включает Telegram; LIVE=0 позволяет запускать API локально без poller. Данные — data/rent.sqlite3. Источник Telegram: разовая выгрузка за 10 дней и заполнение карточек из проверенного JSON. Постоянное сканирование отключено (`TELEGRAM_SYNC_ENABLED=0`). Исходные даты, фото и ссылки сохраняются. Удаления импортированных постов сверяются отдельно: `TELEGRAM_DELETION_CHECK_INTERVAL=900` — раз в 15 минут, `TELEGRAM_READER_USER_ID` — ID временного аккаунта. Новые посты эта проверка не импортирует.

PUBLISH_CHAT_ID/PUBLISH_THREAD_ID — публикации без комиссии; PUBLISH_PAID_CHAT_ID/PUBLISH_PAID_THREAD_ID — агентские. Пустые значения отключают публикацию. Пока обсуждение не подключено, его кнопка недоступна.

Один FastAPI-процесс, SQLite/WAL, 256 MiB RAM. Node, Redis и Postgres для запуска не нужны. Фото отправляются в чат бота; Telegram хранит их и готовит размеры. Сервер хранит file_id и передаёт фото без обработки, скрывая токен. Фото публичных постов браузер загружает напрямую с Telegram CDN. Галерея — PhotoSwipe (MIT, web/vendor).

Для чтения канала заполнить TELEGRAM_API_ID/TELEGRAM_API_HASH с my.telegram.org, TELEGRAM_SOURCE и TELEGRAM_TOPICS в .env. Выполнить `python scripts/telegram_login.py` интерактивно. Сессия data/telegram-reader.session принадлежит одному процессу; коды входа и пароль в .env не сохраняются. Используйте отдельный аккаунт без личной переписки, состоящий в источнике. Сессия даёт доступ к аккаунту; отозвать её можно в Telegram → Настройки → Устройства.

Импорт заменяет прежний каталог выбранного канала; самостоятельные объявления и настройки сохраняются. Сообщения и уведомления не отправляются.

Карта Еревана — MapLibre (BSD-3-Clause), данные OpenStreetMap через OpenFreeMap напрямую в браузере. Подписи на русском, где перевод есть; иначе латиница или исходное название. Примерные координаты сохраняются для опубликованных объявлений; если дом не найден, используется указанный район. Nominatim: один запрос в секунду на приложение, кэш на 30 дней. Разовое дополнение: `docker compose exec app python scripts/fill_locations.py`; периодического обхода нет. Провайдер меняется через GEOCODER_URL; пустое значение отключает карту. [Правила Nominatim](https://operations.osmfoundation.org/policies/nominatim/).

## Изменения и обслуживание

Редактировать web/app.js, core.js, style.css и index.template.html; затем `python build.py`.

```sh
pip install -r requirements-dev.txt
python -m pytest -q
node tests/test_core.js
python tests/mobile_smoke.py
python tests/mobile_moderation.py
python tests/mobile_gallery.py
python tests/mobile_source.py
python tests/mobile_feed.py
python tests/mobile_maps.py
```

Для браузерных тестов установить Chromium: `python -m playwright install chromium` или задать CHROMIUM_PATH.

Перед обновлением: `python scripts/backup.py --database data/rent.sqlite3 --output /secure/backup.sqlite3`. Копия исключает реквизиты проверки. Сохранять том и private.key; обновлять только app, не затрагивая соседние сервисы. HTTPS-примеры — deploy/. Один токен — один poller.

Документ можно проверить на [официальной русской странице e-cadastre](https://www.e-cadastre.am/ru/application/docview) по номеру и паролю, которые запрашивают у автора. Автоматическая проверка пока не подключена: официальная форма требует CAPTCHA. Интерфейс не принимает реквизиты и копии документов; проверка личности и полномочий — отдельные действия.

.env, ключи, базы, фотографии и экспорты не публикуются. Перед push обязательны ревью и проверка секретов.
