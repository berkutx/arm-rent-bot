# Работа с проектом

Прочитать README.md, docs/PRODUCT.md, docs/VERIFICATION.md и docs/DEPLOYMENT.md.

## Изменения и проверки

- Исходники интерфейса — web/app.js, core.js, style.css, index.template.html. Собирать `python build.py`; готовый HTML вручную не править.
- Проверять `python -m pytest -q`, `node tests/test_core.js`; для UI — оба tests/mobile_*.py.
- Один FastAPI-процесс, SQLite/WAL, очередь и long polling. Не запускать второй poller с тем же токеном.
- Секреты только в локальном .env. Не выводить токен, ключ или реквизиты документов в сообщения и логи.
- При развёртывании сначала осмотреть соседние сервисы. Не менять общий Nginx, контейнеры и тома других проектов.

## Правила продукта

- Mobile first, минимум действий. Цена, адрес, тип и комнаты задаются вручную; описание сохраняется дословно.
- Разрешено извлекать только телефон по строгой полной маске +374 или +7. Не угадывать код страны, не выбирать один из нескольких номеров, не заполнять явно очищенное поле повторно.
- Даты аренды и время в пути необязательны. Не вычислять их из описания или адреса.
- Нет лайков, избранного, рейтингов, TTL, автопродлений и напоминаний об актуальности. «Сдано» вручную; публикационная дата не меняется при правке или модерации.
- Телефон не подтверждает личность и не влияет на ранжирование. Риелторы исключаются из подборки совпадающих телефонов с обеих сторон.
- Бан требует причину; снять его может только админ. Автор видит свои статусы и причину бана.
- Просмотры уникальны по проверенной Telegram-авторизации. ID посетителей не публикуются.
- sample=true, document_status=none для учебных примеров. Демо и рабочая база разделены; примеры не отправляются в Telegram.
- Условная цена: при регистрации применять 450 000, а не базовые 400 000. Регрессия — demo-conditional.
- Не выдавать слова автора, фотографию или распознанный документ за подтверждение права. Официальная сверка и проверка личности — ручные, добровольные, отдельные.
- Загрузка/OCR документов и счётчик постов автора отложены; см. docs/TODO.md.

Перед публичной отправкой проверить именно содержимое коммита на секреты и реальные персональные данные. Не публиковать research, data, .local, выгрузки и сведения о частном сервере.
