# Работа с проектом

- Прочитать README.md. После правок UI запускать build.py; готовый HTML вручную не редактировать.
- Проверять pytest, tests/test_core.js и затронутые мобильные сценарии.
- Источник Telegram: разовая выгрузка за 10 дней, смысловой разбор в JSON и импорт. Постоянное наблюдение отключено. Даты, фото, ссылки и автор — из Telegram. Импорт не отправляет сообщения и заменяет только старый импорт выбранного канала.
- Подача с Telegram-авторизацией. Контакт принадлежит автору; без username связь только в обсуждении. Нет передачи запросов через бота.
- «С комиссией» — только агенты с явной комиссией; раздел учитывают поиск, подписки и публикация.
- Из описания извлекать только однозначный телефон +374/+7. Остальные поля задаются вручную; для разового импорта — из проверенного JSON. Телефон не подтверждает личность и не влияет на выдачу.
- Нет лайков, рейтингов, TTL и напоминаний об актуальности. «Сдано» вручную; исходная дата не меняется.
- Бан требует причину; снимает админ. Автор видит статусы. Просмотры уникальны по Telegram, ID посетителей скрыты.
- Условная цена регистрации: 450 000, а не 400 000. Проверка документа, личности и полномочий — отдельные действия. OCR и загрузки документов нет.
- Проверка документа: переход на официальную русскую страницу e-cadastre; реквизиты запрашивают у автора. Автопроверка пока не подключена из-за CAPTCHA. Интерфейс не принимает реквизиты документов.
- Фото принимает и обрабатывает Telegram; сервер хранит идентификаторы и проксирует готовые размеры. Не передавать клиенту URL с токеном Telegram.
- Один poller. Секреты только в .env; перед push ревью и проверка секретов. При деплое сохранять данные и ключ, не менять соседние контейнеры и Nginx.
