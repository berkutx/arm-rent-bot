# Размещение

Один процесс uvicorn с SQLite/WAL и long polling. Для готовой сборки Node не нужен.

## Docker

```sh
cp .env.example .env
# Заполнить .env локально.
docker compose up -d --build
curl http://127.0.0.1:18080/healthz
```

Compose ограничивает приложение 256 MiB RAM и 0.5 CPU. Порт опубликован только на loopback, данные хранятся в отдельном томе. Контейнер работает без root, с файловой системой только для чтения и ограниченными логами.

Включать LIVE=1 после настройки BOT_TOKEN, BOT_USERNAME, ADMIN_IDS и PUBLIC_URL. PUBLISH_CHAT_ID оставить пустым до проверки в согласованном тестовом чате. Не запускать несколько экземпляров с одним токеном.

## HTTPS и Telegram

Настроить доверенный HTTPS и Main Mini App в BotFather. Проверить открытие с меню и startapp, BackButton, клавиатуру и safe areas в Telegram Android/iOS.

Для временного теста доступен deploy/compose.tunnel.yaml с cloudflared. Адрес меняется при пересоздании туннеля; обновлять PUBLIC_URL и настройки бота. Это не постоянное размещение.

Для HTTPS на публичном IP есть deploy/render_ip_config.py. По умолчанию прокси использует порт Docker 18080; для запуска через systemd указать `--upstream-port 8000`. Перед применением проверить доступность 80/443 и действующую конфигурацию Nginx. Для короткого IP-сертификата обязательны автоматическое продление и reload; настройки сверять с [Let's Encrypt](https://letsencrypt.org/2026/03/11/shorter-certs-certbot/).

Не перезаписывать общий Nginx и соседние Compose-проекты. systemd-пример — альтернатива Docker, а не второй процесс.

## Данные и обновление

- Ограничить права на каталог данных и private.key. Не добавлять их в Git и Docker-образ.
- До обновления создать резервную копию: `python scripts/backup.py --database data/svoi.sqlite3 --output /secure/backup.sqlite3`.
- Резервная копия исключает реквизиты проверки, но содержит контакты объявлений. Хранить её с ограниченным доступом.
- При обновлении сохранить том, исходный ключ и дату публикаций. Собрать образ, проверить его с временной БД без сети, затем обновить только приложение.
- Контролировать место на диске, healthz и резервные копии. Проверить восстановление отдельно.

До публикации в основной канал проверить автора, арендатора и администратора реальными аккаунтами, доставку подписки и /stop, контакт без username и загрузку 10 фото.
