# Проверки

```sh
python build.py
python -m pytest -q
node tests/test_core.js
python tests/mobile_smoke.py
python tests/mobile_moderation.py
python tests/mobile_gallery.py
```

Python-тесты используют временную SQLite: Telegram-авторизация, приватные реквизиты, доступ автора/админа, модерация, даты, условные цены, фотографии, подписки и уникальность просмотров. Telegram и e-cadastre не вызываются.

JS-тесты проверяют фильтры, календарный возраст и строгие маски телефона. Мобильные сценарии проверяют ширины 320/360/390/430, формы, навигацию, модерацию, PhotoSwipe, возврат из галереи и подачу с комиссией. Это эмуляция Chromium; она не заменяет Telegram на реальных Android/iOS.

Для системного Chromium задать CHROMIUM_PATH. Иначе установить браузер командой `python -m playwright install chromium`.

Контейнерные проверки без сети: deploy/smoke_catalog_runtime.py и deploy/smoke_photo_memory.py. Использовать только временную БД, не рабочий том.

Перед публичным коммитом: проверка gitleaks, просмотр списка файлов и отдельная проверка отсутствия .env, ключей, БД, реальных экспортов и сведений о сервере. Сканер не заменяет ручное ревью.

Фактическая проверка права собственности, полномочий и личности проводится человеком по VERIFICATION.md; автотесты этого не доказывают.
