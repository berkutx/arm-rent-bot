# Отложено

- Загрузка и OCR копии документа: пока не добавлять в код и UI. При возвращении к задаче документы должны быть доступны только администраторам и удаляться по сроку/решению. OCR не подтверждает собственника.
- Счётчик постов автора в Telegram: вернуться при подключении API с пользовательской авторизацией. Заглушку не показывать.
- Просмотр фотографий: альбом в ленте, крупный просмотр с увеличением, миниатюры и сохранение места при возврате. Сценарий пока обсуждён, не реализован.
- Комментарии из связанной группы: подключить после согласования канала и прав бота.
